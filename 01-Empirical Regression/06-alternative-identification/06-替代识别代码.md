## 1. IV/2SLS

```stata
reghdfe endogenous_x excluded_iv controls, absorb(fe_list) vce(cluster cluster_id)
reghdfe y excluded_iv controls, absorb(fe_list) vce(cluster cluster_id)
ivreghdfe y controls (endogenous_x = excluded_iv), ///
    absorb(fe_list) cluster(cluster_id) first
ereturn list
```

多个用户确认的候选 IV：

```stata
tempname iv_handle
if "$CODEX_PARTIAL_FAILURES"=="" global CODEX_PARTIAL_FAILURES 0
postfile `iv_handle' str64 candidate_iv double rc beta se N using "06_iv_candidate_results.dta", replace
foreach z in 用户确认的IV列表 {
    capture quietly ivreghdfe y controls (endogenous_x=`z'), ///
        absorb(fe_list) cluster(cluster_id) first
    local run_rc = _rc
    if `run_rc' == 0 {
        local run_beta = _b[endogenous_x]
        local run_se   = _se[endogenous_x]
        local run_N    = e(N)
    }
    else {
        global CODEX_PARTIAL_FAILURES = $CODEX_PARTIAL_FAILURES + 1
        local run_beta = .
        local run_se   = .
        local run_N    = .
    }
    post `iv_handle' ("`z'") (`run_rc') (`run_beta') (`run_se') (`run_N')
}
postclose `iv_handle'
preserve
use "06_iv_candidate_results.dta", clear
export delimited using "06_iv_candidate_results.csv", replace
restore
display "CODEX_PARTIAL_FAILURES=$CODEX_PARTIAL_FAILURES"
```

每个候选 IV 的第一阶段统计量、弱工具变量诊断、过度识别检验和内生性检验必须同时保留在该次运行的完整 Stata log 中；上面的结构化台账只记录可跨规格直接比较的二阶段结果，不得用它替代诊断 log。

## 2. 控制函数

```stata
regress endogenous_x excluded_iv controls i.year, vce(cluster cluster_id)
predict double first_resid, residuals
regress y endogenous_x first_resid controls i.year, vce(cluster cluster_id)
test first_resid
```

非线性结果模型按真实模型替换第二阶段并重新确认控制函数假设。

## 3. Heckman selection

```stata
heckman outcome x controls, ///
    select(observed = exclusion_for_selection selection_controls) ///
    twostep vce(cluster cluster_id)
estimates store heckman_twostep

heckman outcome x controls, ///
    select(observed = exclusion_for_selection selection_controls) ///
    mle vce(cluster cluster_id)
estimates store heckman_mle
```

## 4. 动态面板

```stata
xtset panel_id year
xtabond2 y L.y x controls i.year, ///
    gmm(L.y x, lag(2 用户最大滞后) collapse) ///
    iv(controls i.year) twostep robust small
estat abond
estat sargan
```

## 5. DDD

```stata
gen ddd = treated * post * eligible
reghdfe y ddd treated#post treated#eligible post#eligible controls, ///
    absorb(panel_id year eligible#year) vce(cluster cluster_id)
```

## 6. SCM、SDID 与交互固定效应

```stata
synth outcome predictors, trunit(treated_unit) trperiod(treat_year) ///
    keep("scm-alternative.dta") replace

fect outcome treated controls, index(unit_id year) method(ife) force(two-way) ///
    r(用户因子数) se nboots(用户次数)
```

## 7. AIPW/IPWRA

```stata

teffects ipwra (outcome outcome_controls) ///
    (treated treatment_controls, logit), ate

```

## 8. RCT 不依从：assignment IV

## 9. Spatial IV/GMM

```stata
spset region_id
spmatrix create contiguity W, normalize(row) replace
spregress y x controls, gs2sls dvarlag(W) ///
    ivarlag(W: endogenous_x) iv(excluded_iv) vce(robust)
estat impact
```

## 10. Frailty 与 IPCW

Frailty：

```stata
stset exit_time, failure(event==1) id(subject_id)
stcox exposure controls, shared(cluster_id)
streg exposure controls, distribution(weibull) frailty(gamma) shared(cluster_id)
```

IPCW：

```stata
gen uncensored = event==1
logit uncensored exposure controls
predict double p_uncensored, pr
gen double ipcw = 1/p_uncensored
stcox exposure controls [pw=ipcw], vce(cluster cluster_id)
```

权重模型、时间顺序、截断和稳定化必须在 Plan 中确认。
