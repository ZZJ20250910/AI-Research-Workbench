# 01 初始化检查代码

本文件只用于确认终版数据能够被 Stata 读取，并取得建立 `02数据索引.md` 所需的最少信息。不得在 01 阶段检查平行趋势、处理支持、阈值、donor pool、匹配质量、随机分配、时间序列性质、空间结构、比例风险或其他方法诊断；这些内容留给 02—04。

对每个终版数据文件复制一次下面的代码块到项目 `AI-Work/Temp/01try.do`，只替换文件名称和绝对路径。不得直接运行或修改本文件。

```stata
display "===== 数据文件：替换为文件名 ====="
display "完整路径：替换为DTA绝对路径"

use "替换为DTA绝对路径", clear
describe, fullnames
count
summarize
misstable summarize
```

CSV 或 XLSX 只把 `use` 替换为对应的只读导入命令，其余代码不变。01 阶段不根据当前方法追加其他代码。
