# 01 项目初始化

只完成正式估计前的项目初始化、信息归档、终版数据盘点和软件预检。不要在本模块中制定完整回归计划、运行基准估计或稳健性检验。

## 一、开始时读取

1. 完整读取能力包根目录 `00A-方法选择.md`，核实用户选择的方法代码、中文名称和阶段分流。
2. 方法选择后直接按 00A 的阶段分流执行，不读取其他方法说明层。
3. 检查用户在当前消息和已提供材料中是否已经给出所需信息，只追问缺失项。

## 二、收集必要信息

### 项目情况

- 研究主题和目的；
- 大致准备进行哪些估计；
- 可读取的论文初稿、do-file、说明文件或项目文件夹。

### 数据情况

- 本次实证可能涉及的终版数据文件准确路径；
- 清单尽可能全面，但不提供同内容的 CSV/DTA、多版本副本或变量构造中间文件；
- 用户已经明确的关键变量及用途。

如果用户只提供含大量数据的目录，先请用户指出终版文件；不要遍历全部前置数据替用户筛选。同一数据同时存在 CSV 和 DTA 时：变量名、变量数、观察数和用户说明均表明内容相同时，Stata 项目只索引 DTA；任一项不一致或尚未核实时，两者都不读取并请用户指定终版。多版本副本按用户明确指定版本保留；用户未指定时不得根据文件名或日期猜测。

### 工作目录

由用户预先建立并指定 `AI-Work` 的准确路径。在获得准确路径前不创建文件，不猜测目录，也不向原始数据目录写中间文件。

## 三、读取项目材料

根据授权读取论文、代码、说明或项目目录，用于确认研究目的、变量、计划模块、数据关系和尚待确认事项。只记录实际读取内容；文件名或旧代码不能单独证明研究含义，无法确认时标记“待用户确认”。

## 四、建立 AI-Work

只在用户确认的 AI-Work 内建立并保留：

```text
AI-Work/
├─ Inf/
├─ Plan/
├─ Temp/
├─ Reg/
└─ Result/
```

已有目录不删除、不清空。将 `assets/AI-Work项目总说明.md` 复制为 `AI-Work/Inf/00-项目总说明.md`，立即写入 AI-Work 与能力包的真实绝对路径、`W01 标准实证流程`、当前方法代码和中文名称、当前 Skill、项目初始化状态与更新时间。

紧接着创建 `AI-Work/Temp/00-01-int执行状态.md`，固定记录：项目材料读取、目录创建、01项目信息、02数据索引、每个终版数据文件的预检、进度锚点复读，逐项使用“待运行／运行中／成功／失败／受阻”。把 01 在进度锚点中标为“进行中”，写入该状态文件绝对路径，保存后再次完整读取确认。

如果状态文件已经存在，视为中断恢复：先完整读取进度锚点、状态文件、现有 Inf、`01try.do` 和 `01try.log`，从第一项非终态任务继续；成功且对应文件存在的任务不得自动重做。

## 五、建立 Inf

### `01项目信息.md`

记录项目主题、目的、用户计划的估计、已读取材料的准确路径、已确认核心变量和待确认事项。不要把一般计量知识扩写成用户已经决定的方案。

### `02数据索引.md`

按以下顺序记录：

1. 终版数据的绝对路径、格式、内容、用途和读取状态；
2. 用户或材料明确提到的变量：准确变量名、所在文件、用途和来源；
3. 每个终版数据文件的全部准确变量名和可读标签；
4. 已知分析结构：只记录用户或现有材料已经明确的观察层级、候选唯一键、面板/时间/空间字段及当前方法必需字段；未经代码验证的项目统一标记“待后续阶段验证”，不得在 01 中扩展检查。

只对终版文件完整索引变量。中间文件最多记录用途和位置，不做完整变量/描述统计。

## 六、编写简单预检

在第一次调用 Stata 前完整读取根目录 `00C-Stata调用方法.md`。在 `AI-Work/Temp` 创建 `01try.do`，文件开头只写：

```stata
clear all
set more off
```

随后完整读取同目录 `01-初始化检查代码.md`，对每个终版数据文件复制一次其中唯一的代码块，只替换文件名称、绝对路径和导入命令。文件末尾固定写：

```stata
display "CODEX_STATA_COMPLETE=1"
exit, clear
```

01 只取得变量名、标签、观察值、描述统计、缺失概况和读取错误；不进行任何方法专属结构检查或诊断，不引入循环、`postfile`、自动结果数据库或回归命令。中文路径无法识别时可在 Temp 建英文别名或硬链接，不移动原数据。

## 七、运行与更新索引

按 `00C` 调用 Stata，等待进程退出，完整读取 `01try.log`，核对完成标记和错误。普通预检不强制计时 CSV。

在 `02数据索引.md` 补充每个终版文件的观察值、变量数、数值变量描述统计、缺失概况和读取错误。统计必须来自实际运行；失败范围如实记录。观察层级、唯一键和当前方法必需字段只有在用户或现有材料已经明确时才记录；01 不运行代码验证它们，统一标记“待后续阶段验证”。

每完成一个终版数据文件，立即更新 `00-01-int执行状态.md`，再完整读取、更新并复读进度锚点；不得等全部文件完成后一次补写。

如果 Stata 未找到、无法启动或部分文件无法读取，保留 do/log，记录阻塞，不伪造统计。

## 八、收尾

1. 读取 `00A`，找出当前方法下剩余已配置阶段，不读取候选阶段内容。
2. 完整读取 `AI-Work/Inf/00-项目总说明.md`。
3. 核对 `00-01-int执行状态.md`：所有任务均为终态后，将本模块记录为 `01 项目初始化`；存在失败或受阻时记录为部分完成或受阻，不得写成已完成。
4. 更新项目方法、Skill、阶段、Inf 文件路径、结果/日志位置、尚未完成和下一步。
5. 保存后再次完整读取进度锚点确认。
6. 报告五个目录、Inf 文件、do/log 和 Stata 预检状态，提醒用户检查 Inf。
7. 显示当前方法剩余阶段并等待用户选择，不自动进入下一阶段。
