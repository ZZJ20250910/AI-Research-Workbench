## 4. 统计中介与间接效应

```stata
sem (mechanism <- x controls) (y <- mechanism x controls), ///
    vce(cluster cluster_id)
nlcom indirect: _b[mechanism:x] * _b[y:mechanism]
nlcom direct: _b[y:x]
nlcom total: _b[y:x] + _b[mechanism:x] * _b[y:mechanism]
```

Bootstrap 间接效应：

```stata
capture program drop med_effect
program define med_effect, rclass
    quietly regress mechanism x controls
    scalar a = _b[x]
    quietly regress y x mechanism controls
    return scalar indirect = a * _b[mechanism]
end
preserve
xtset, clear
bootstrap indirect=r(indirect), reps(1000) seed(20260927) ///
    cluster(cluster_id) idcluster(bs_cluster_id): med_effect
restore
```

## 9. Local projections

```stata
xtset panel_id year
forvalues h=0/用户最大预测期 {
    gen F`h'_y = F`h'.y
    reghdfe F`h'_y shock controls, absorb(panel_id year) vce(cluster cluster_id)
    estimates store lp`h'
}
coefplot lp0 lp1 lp2 lp3, keep(shock) vertical yline(0)
```

## 10. 事件动态路径

```stata
gen event_time = year-first_treat_year
forvalues k=用户事前期数(-1)2 {
    gen lead`=abs(`k')' = event_time==`k' & first_treat_year<.
}
forvalues k=0/用户事后期数 {
    gen lag`k' = event_time==`k' & first_treat_year<.
}
reghdfe y lead变量列表 lag变量列表 controls, ///
    absorb(panel_id year) vce(cluster cluster_id)
testparm lead变量列表
```

## 11. 结构反事实（Python）

```python
baseline_solution = solve_model(estimated_parameters, baseline_primitives)

    "baseline": baseline_primitives,
    "policy_low": {**baseline_primitives, "policy": 用户低情景},
    "policy_high": {**baseline_primitives, "policy": 用户高情景},
}
results = {}
for name, primitives in scenarios.items():
    solution = solve_model(estimated_parameters, primitives)
    results[name] = summarize_outcomes(solution)

```
