# AI Research Workbench：整包安装入口

本文件供负责安装、迁移或更新本 Workbench 的 AI 读取，不是日常科研任务说明。用户要求安装本文件夹时，必须先完整读取本文件，再转入指定的正式安装规程。

## 一、识别整包和当前位置

1. 以本文件的真实绝对路径为准：本文件的父目录就是 `workbenchRoot`。用户把文件夹放在哪里，那里就是正式源目录，不要求用户另行说明路径。
2. 把 `workbenchRoot` 下的 `ai-research` 和所有以“两位数字加连字符”开头的文件夹视为一个完整 Workbench。不得只安装其中某一个能力包。
3. 先进行非递归只读检查，至少确认以下项目存在：

```text
workbenchRoot/
├── README FOR HUMAN.md
├── README FOR AI.md
├── ai-research/SKILL.md
├── 01-Empirical Regression/00D-静默安装与本机适配.md
└── 一个或多个以两位数字加连字符开头的能力包目录
```

4. 如果正式安装规程存在，不要在本阶段递归读取其他能力包，也不要自行重新设计安装方法。

## 二、整包安装的架构要求

安装结果必须遵守以下结构：

- `workbenchRoot` 是全部工作流的唯一可编辑源；
- Codex 全局 Skill 注册目录中只注册 `ai-research`；
- `01-Empirical Regression`、`02-Data Paper`、`03-Writing DNA`、`04-Defensive Writing Revision`、`05-Paper to Slides`、`06-Econ Reference Matcher`、`07-Study Paper` 以及以后新增的编号能力包，不得分别注册成独立斜杠命令；
- `/ai-research` 运行时只非递归读取一级编号目录名，用户选择后才读取相应 `ENTRY.md`；
- 优先通过 Junction 或符号链接让全局 `ai-research` 指向本包内的 `ai-research`；宿主环境不支持链接时，才使用正式安装规程允许的复制回退方式；
- 不移动、删除或拆散用户复制来的 Workbench，不把具体科研项目、数据或论文放入 Workbench；
- 路径、本机 Codex 环境和 Stata 调用方式的适配，必须按照正式安装规程执行，不依据猜测改写。

## 三、安装授权确认

完成整包识别后，先判断用户是否已经明确要求安装、迁移或更新本 Workbench：

- 如果用户已经明确说要安装、迁移、配置或更新，视为已经授权，直接进入下一节，不重复确认。
- 如果用户只是要求阅读本文件、查看文件夹或了解内容，尚未明确授权安装，则先向用户简短说明检测到的 Workbench 位置、编号能力包和唯一总入口，并询问：`是否现在安装整个 AI Research Workbench，并注册 /ai-research？`
- 用户确认前只进行只读检查，不创建链接、不复制注册入口、不改写配置，也不启动 Stata。
- 不询问用户要逐个安装哪些编号能力包。编号能力包共同留在 `workbenchRoot` 中，实际注册的始终只有 `/ai-research`；因此安装对象是整个 Workbench，而不是若干独立斜杠命令。
- 用户拒绝或只想查看时停止安装，并保持所有文件不变。

## 四、确认后的交互方式

整个安装过程默认静默进行：

- 能从文件系统、环境变量、注册表或现有配置确定的信息，不询问用户；
- 除宿主系统强制要求的权限或安全确认外，不在安装过程中逐步提问；
- 不逐项汇报内部扫描过程；
- 安装和基础适配完成后，只按正式规程给出一次简短结果；
- 如果正式规程要求使用简单 do-file 对 Stata 调用方式测速，先完成基础安装，再向用户索取该文件路径，不提前搜索或运行用户科研文件。

## 五、转入正式安装规程

完成上述识别和只读检查后，立即执行以下操作：

1. 完整读取：

```text
<workbenchRoot>\01-Empirical Regression\00D-静默安装与本机适配.md
```

2. 将该文件视为本 Workbench 当前唯一的正式安装、迁移、本机路径适配、Stata 探测、测速和校验规程。
3. 从 00D 第一节开始顺序执行，不得只做摘要后停止，不得把其中的自动步骤重新交给用户手工完成。
4. 00D 中的 `workbenchRoot` 必须解释为本文件父目录的真实绝对路径；全部旧路径均按 00D 的规则静默适配。
5. 如果 00D 与本文件在具体执行步骤上存在差异，以 00D 为准；本文件只规定整包范围、唯一入口和正式规程的交接关系。

如果 00D 缺失或无法读取，停止安装并一次性报告缺失文件的准确预期位置；不得自行编造替代安装规程。
