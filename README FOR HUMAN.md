# AI Research Workbench

## 这是什么

AI Research Workbench 是一套可自行查看、修改和迁移的科研 AI 工作流集合。它把不同科研任务分别放在独立能力包中，同时只对外提供一个统一入口：

```text
/ai-research
```

输入该命令后，AI 先显示当前已有的能力包。用户作出选择后，AI 才读取相应能力包的入口和具体工作流，不会一开始就遍历全部文件。

## 如何使用

1. 在 Codex 中输入 `/ai-research`。
2. 从一级菜单中选择需要的能力包。
3. 如果能力包还有下一层菜单，继续选择具体方法或阶段。
4. 告诉 AI 本次任务、材料或项目文件夹的准确位置。
5. AI 按所选工作流执行，并把产出保存在相应项目目录中。

## 当前能力包

### 01. Empirical Regression

用于已有基础数据和较清晰研究框架后的实证分析，不负责从零构思研究选题。目前支持：

- 常规回归与面板、DID、IV、RDD、合成控制与 SDID；
- 匹配与重加权、随机实验、因果机器学习；
- 时间序列、空间计量、结构估计；
- 生存分析与流行病学模型，以及用户已有明确材料的其他方法。

所有方法共用项目初始化、基准估计、通用诊断、方法专属识别检验、高级敏感性、替代识别、机制/动态扩展和异质性等阶段。方法选择只决定调用哪些阶段，不会为每种方法复制整套流程。

每个执行阶段在自己的目录中保存该阶段的完整代码。重复使用的检验只保存一份，特有检验集中在方法专属阶段；AI 会把用户选中的代码复制到项目 `Temp` 后替换路径和变量，不修改 Workbench 中的代码原件。

正式使用时，用户为项目单独准备 `AI-Work` 文件夹。工作流会在其中管理信息、计划、试运行、正式回归和结果，不把项目文件混入本 Workbench。

### 02. Data Paper

用于完整阅读实证论文及其附录、审稿意见、编辑决定或回复材料，形成中文 Markdown 导读。目标是让没有阅读原文的协作者能够理解论文，并尽可能接手数据、识别策略和实证结果。

### 03. Writing DNA

用于从一批完整文章中提炼可复用的写作风格，包括语言习惯、文章结构、选题逻辑、材料策略、认知框架和视觉风格，并形成 `Writing-DNA.md` 等风格文件。

### 04. Defensive Writing Revision

用于诊断和修改学术论文中的防御性写作，让论文更直接地呈现受证据支持的贡献，同时保留必要的限定条件、证据状态、竞争性解释和概念层级。诊断不等于授权修改，AI 只有在用户明确要求后才会改动稿件。

### 05. Paper to Slides

用于把论文及附录转化为忠实、可独立编译的 LaTeX Beamer 演示文稿，并生成 PDF、逐页计时讲稿、来源记录和构建说明。默认忠实呈现论文，不自动扩展为审稿或研究设计。

### 06. Econ Reference Matcher

用于为经管论文中的具体句子、段落、理论机制或贡献表述寻找并核验真正能够承担引用的文献。它区分直接支持、理论支持、文献对话、待全文核验候选和主题相近但不可引用的文献，并可按用户提供或可核验的 SSCI、JCR、ABS/AJG、FT50、UTD24 等条件筛选。

### 07. Study Paper

用于为论文生成可定位的逐段 Markdown 地图。它沿用原文的章节结构，从头到尾以 `P-1`、`P-2` 等连续编号每个正文段落，并在 `Temp` 中保留一份使用相同段落标签的原文 `source-map.md`，让 AI 可以按 `P-XX` 直接找到原段；PDF 页码、章节和原文开头锚点用于辅助校验。段落内容按原文语言忠实压缩为一至三句话，优先一句话，不加入评价或额外分析。

后续增加的编号能力包遵循同样的入口和按需加载规则。

## 文件夹如何工作

```text
AI Research Workbench/
├── ai-research/                    唯一注册的总入口
├── 01-Empirical Regression/        实证回归能力包
├── 02-Data Paper/                  实证论文导读能力包
├── 03-Writing DNA/                 写作风格蒸馏能力包
├── 04-Defensive Writing Revision/  防御性写作诊断与修改能力包
├── 05-Paper to Slides/              论文转 LaTeX 学术演示能力包
├── 06-Econ Reference Matcher/       经管论文引用匹配与证据核验能力包
├── 07-Study Paper/                   论文逐段定位与忠实压缩能力包
├── README FOR HUMAN.md             本说明
└── README FOR AI.md                整包安装说明入口
```

每个编号文件夹都是一个相对独立的能力包。`ai-research` 只负责显示一级菜单和把任务交给用户选中的能力包。增加新的编号文件夹后，总入口可以自动把它显示在菜单中。

## 几项重要原则

- 只注册 `/ai-research`，不把每个能力包分别注册成斜杠命令。
- Workbench 保存工作流，具体论文、数据、回归结果和临时文件保存在各自项目目录。
- AI 只在用户选择后读取对应能力包，避免无关内容占用上下文。
- 原始数据、论文和其他用户材料不应因运行工作流而被覆盖或删除。
- 能力包可以直接在本文件夹中人工查看和修改；这里的文件是正式源文件。

## 复制给其他人

复制整个 `AI Research Workbench` 文件夹，不要只复制全局 Skill 入口或某一个子文件夹。

复制完成后，让对方的 AI 完整读取根目录下的 [`README FOR AI.md`](README%20FOR%20AI.md)。如果用户尚未明确要求安装，AI 会先确认是否安装整个 Workbench；确认后再自动注册和适配。用户不需要手动逐个注册能力包。
