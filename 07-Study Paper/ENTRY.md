# Study Paper：入口

本能力包只有一个工作流，不设置第二层编号菜单。

1. 用户在 AI Research Workbench 中选择 `07-Study Paper` 后，完整读取同目录下的 `SKILL.md`。
2. 如果用户已经给出论文文件、论文索引及条目标识，或最终 Markdown 的位置，直接按照 `SKILL.md` 解析并执行，不重复询问已提供的信息。
3. 如果尚未提供可定位论文的信息，只询问论文文件路径，或者论文索引路径及条目标识。如果尚未给出输出位置，只在其确实无法从索引或用户指定位置推定时询问。
4. 按原文章节结构生成从 `P-1` 开始连续编号的逐段 Markdown 地图。每段摘要优先一句、最多三句，只忠实压缩原文，不扩展为评价、论证功能分析、实证接手指南或文献匹配。
5. 在最终输出根目录下的 `Temp` 中保留一份按真实阅读顺序整理的 UTF-8 `source-map.md`，以与最终概括一致的 `P-XX` 标签保存每个原文段落，并在最终 Markdown 开头记录其绝对路径。其他中间文件也必须放入 `Temp`；最终 Markdown 才能放在用户指定的位置。不得修改原论文或论文索引。
6. 不读取其他 Workbench 能力包。处理 PDF、DOCX 等格式时，可以使用宿主已有的文件格式技能，但不得因此扩大任务范围。
7. 默认只做一次主文本提取，并以机械检查筛出断句、乱码和公式异常后定点核对原页；不得常规生成多套重复提取物或逐页渲染全文。最终 MD 中的定位信息使用单行引用格式，且不得带入损坏的数学字形。
